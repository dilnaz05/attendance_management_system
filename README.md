University Attendance Management System

Frontend: React, Bootstrap, Axios
Backend: Java 17, Spring Boot 3, Spring Security, JWT, Hibernate
База данных: PostgreSQL

Регистрация и вход пользователей (JWT токены).
Разграничение прав пользователей (admin и user).
Управление студентами (CRUD), университетами (CRUD), дисциплинами (CRUD).
Фильтрация и поиск студентов по имени, курсу, университету, дисциплине.
